# on-record

What French elected officials actually do, on the record — not what they say.

The first source is the Assemblée nationale: every public vote of every deputy,
with the group they sat in on that day. The project is built to take more
sources later (Senate, HATVP declarations, presidential programmes) without
changing its shape.
